# Chandraditya Sati - AI Engineer & Developer Portfolio

A modern, high-performance portfolio application rewritten as a React + TypeScript SPA with Vite, showcasing machine learning, IoT, and web engineering projects along with classical tabla achievements.

## Features

- **Hero & Interactive Intro**: Dynamic typewriter role switching, ambient floating particle canvas network, rotating neon profile ring with floating skill badges, and direct CV download.
- **Animated Stats Bar**: Viewport intersection observer counting up completed projects, tech stacks, and credentials.
- **About & Education**: Terminal-inspired `education.json` viewer and classical arts / hobbies showcase (Tabla Visharad).
- **Skills Matrix & Infinite Marquee**: Proficiency gauges and a continuously scrolling technology strip featuring modern dev stack badges.
- **Featured Projects**: Interactive cards with status indicators, Mel-Frequency Cepstral Coefficients music genre classifier, music training platform, and Arduino smart security system with GitHub repositories.
- **Contact & Real-Time Sync**: Integrated contact message submission with Firebase Firestore and synchronized local storage mirror.
- **Admin Dashboard**: Full message management inbox supporting authentication, live Firestore stream, individual deletion, and batch purge.

## Tech Stack

- **Framework**: React 18 with TypeScript
- **Bundler**: Vite
- **Styling**: Valorant Red theme with custom CSS properties, responsive breakpoints, and animations
- **Backend/Data**: Firebase Firestore & Firebase Auth with local fallback mirror

## Running Locally

```bash
npm install
npm run dev
```

Visit `http://localhost:3000`. Navigate to `/#admin` or click "Admin Portal" in the navigation bar to access the management inbox.
